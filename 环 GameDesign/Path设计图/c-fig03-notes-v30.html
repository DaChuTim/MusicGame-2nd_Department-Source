TAMAKI₃ / CHARTER · NOTE TYPES

六类音符与区域

卡组按玩家动作分类；判定只看时间、逻辑角度与接触范围，不看画面像素。
TAP
时间 + 逻辑角度；定位后按键
HOLD
只判头部；持续保持键盘，松手时机定评级
PATH
头尾判定；中段判定组 + 走廊，可跳 1 组
SEEK
滚轮上／下擦带；只判 PERFECT / MISS，±200ms
ANCHOR
成对双押：瞄准任一锚点，同按两键
BELL
圆形范围，目标±130ms；设计上只记收集率
LIMIT
Region；连续停留 200ms 断连，最长 4 拍
BELL ≠ REGION
Bell 是 type=bell 的 Note；只有 Limit 走 Region
Path 的颜色来自配色组（tap / hold / path 单色槽），单条音符可以覆盖；Seek、Anchor 与区域使用固定分类色。
